# Unit Creation System

Консольное приложение на C#, демонстрирующее базовую систему найма юнитов.

## Возможности:

* Создание кастомного юнита (имя + характеристики HP, Speed, Armor, Damage)

* Динамический расчёт цены (сумма характеристик)

* Проверка баланса игрока

* Покупка и добавление юнита в отряд

* Инвентарь с информацией о купленных юнитах

## Цель проекта: Показать понимание ООП, работы с коллекциями и базовой игровой экономики.
